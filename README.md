EducatorAssessmentPro

An AI-powered Streamlit app that helps educators:

    Upload study material (PDF/TXT) and auto-detect core topics
    Generate assessments (MCQ, short answer, essay) at a chosen difficulty
    Grade student short answers with AI-suggested scores + feedback
    Aggregate feedback across a whole class into one report
